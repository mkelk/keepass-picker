The security contract adopted from 1Passchy (MIT, Rafael Santana) and the
text-injection lessons taken from voxtype (MIT) are ideas, not copied code;
they are credited in `README.md`. The plugin invokes KeePassXC, pinentry,

embeds any of them.

projects. "KeePass" is used to describe the database format the plugin reads.
